## Common Commands

1. **Run Laravel Artisan commands:**
   ```bash
   cd api && php artisan <command>
   ```

2. **Run npm/node commands:**
   ```bash
   cd web && npm run <script>
   ```

3. **Git operations:**
   ```bash
   git status
   git add .
   git commit -m "<message>"
   ```

4. **API requests (PowerShell):**
   ```powershell
   Invoke-RestMethod -Uri "<url>" | ConvertTo-Json
   ```

5. **Python scripts:**
   ```bash
   python -c "<code>"
   ```

6. **File operations:**
   ```bash
   Copy-Item -Path "<source>" -Destination "<dest>"
   ```
